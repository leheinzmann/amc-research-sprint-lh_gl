10) Lee: I'm not sure we should keep two different datasets for different kinds of analysis.
    I'd argue it's better to keep a single dataset that is as complete as possible (after cleaning), and that each analysis filters out what's needed.
    Reason: (1) if we need to do any sort of quality control on the data (e.g. manually classifying double-use objs), working with one file is easier.
    (2) We cannot afford to lose accidentally lose information when modifying/merging/analyzing csv files
    (3) It's easier to select relevant columns/items per analysis, instead of having to worry whether the csv file has what we need or not
